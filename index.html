Why this cannot touch your account

Every account ban in Warcraft comes from one place: the anti-cheat system that runs inside the game client while you are connected to Blizzard. It watches the live process for tampering and the network for impossible behaviour. This method never goes near either.

The tool reads the game's data files that are already installed on your computer, in the same way a photo viewer reads a photo. It does not launch the game, does not log in, does not open a connection to Blizzard, and never writes to or modifies a single client file. Because the game client is not running, there is nothing for the anti-cheat to observe, and no session to attach a flag to.

The distinction that matters

The free-camera tricks people get banned for are memory patchers. They edit the running game in real time to detach the camera from your character, which is exactly what the anti-cheat is built to catch. This guide does the opposite: it builds a separate viewer that reads the world's data offline. Nothing is injected, nothing is modified, and your character does not exist in that viewer at all.

What you need

All of it free, none of it tied to an account.

  • A local Warcraft install. Any current Classic client on your disk works, because the viewer reads that install's own data files. The game does not need to be running or even updated to the newest patch.
  • wow.export, the export toolkit by Kruithne. This is the app that contains the built-in 3D world viewer. It is a portable download, so there is no installer and no sign-in.
  • Roughly 4 GB of free memory for continent-scale views, more if you load several zones at once.
  • Optional: a screen recorder such as OBS Studio if you want moving footage rather than stills.

Set it up

  1. Download the viewer

    Get wow.export from its official page at kruithne.net/wow.export, choosing the portable build for Windows or the macOS package. There is a build for each platform, so pick the one matching your machine. Nothing is installed into the game folder and no account is requested at any point.

  2. Point it at your game data

    Launch the app. On first run it detects your Warcraft installations automatically; if it does not, browse to your game folder so it can find the data. It then indexes those local files, which may take a minute the first time. From here on the app works entirely from your disk, so you can even disconnect from the internet and it keeps working.

  3. Open the 3D world viewer

    Inside wow.export, open the 3D map viewer. It renders real terrain, so you are looking at the actual world geometry, textures and objects, not a flat map image. Choose a continent first, then narrow to the zone you want. Older zones from the Classic data set load quickly because there is far less terrain to stream.

Roam the world

Once a zone is loaded you have a free camera: move it with the movement keys while steering with the mouse, exactly like an in-game free-look, and switch between orbiting a point and flying straight through the world. There is no character, no interface, no health bar, no minimap, and no name plates, because none of those exist in the viewer. There is nothing to hide.

This is the answer to the two problems a live free camera cannot solve. You can put the lens anywhere, including places a character could never stand, and you move the camera directly instead of marching a character around and hoping the shot lines up.

What you wantHow the viewer handles it
Free movementFly or orbit the camera anywhere in the loaded terrain
Clean frameNo interface exists, so nothing to toggle off
Impossible anglesCamera is not tied to a body, so clipping through walls is a choice, not a problem
Repeatable shotsReopen the same zone and re-frame the same view any time

The exact key bindings are shown inside the app and differ slightly between the orbit and fly modes, so check the on-screen help the first time you open a zone.

Record the footage

Because the viewer is a normal desktop window, anything that records your screen records your flythrough. Set your recorder to capture the viewer window at a high resolution and a steady frame rate, then move the camera slowly and smoothly, slower than feels right, since fast camera pans read as jitter on playback.

Push the render quality up in the viewer's own settings first, and if your machine can handle it, run the window larger than your final video and downscale afterwards. That single step does more for how cinematic the result looks than any in-app effect.

Going further: real cinematics

Free roaming is the simplest version of what you want. When you are ready to author camera moves rather than fly them by hand, wow.export ships the same pipeline the machinima community uses: a Blender add-on that imports terrain, models and animations straight from your local game data.

With the world in Blender you place a camera and animate its path with keyframes, so a move can be perfectly smooth and repeatable, held at a deliberate speed, and re-rendered at any resolution you like. This is the step where offline editing beats anything the live game can do, because the camera is not a game object at all, it is a curve you drew.

Rules to keep it safe

Do

  • Keep everything offline and read-only. Do not modify files inside your game folder.
  • Close the game before you run the viewer, so there is no doubt about what is touching what.
  • Prefer the portable build, which leaves no trace on the game install.

Do not

  • Do not run free-camera memory patches or dll injections against a live realm. That is the one thing here that carries real ban risk, and this guide never needs it.
  • Do not expect to roam on a live server. There is no legitimate free camera in the running game; the whole point of going offline is that you do not need one.
  • Do not sign in to anything to use these tools. None of them require it.
